# SDL Keyboard Movement Example

A sample Python project utilizing SDL (via Pygame) to render a movable square on the screen controlled via keyboard input (Arrow keys or WASD).

## Requirements

- Python 3.10+
- Pygame

## Setup

1. Create and activate a virtual environment:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running the Application

```bash
python3 main.py
```

### Controls

- **Arrow Keys** or **W / A / S / D**: Move the square (Up, Down, Left, Right)
- **Escape** or **Close Window**: Exit the application
